# oshpoint Telegram Bot

`oshpoint` — это Telegram‑бот для публикации объявлений о продаже,
покупке или обмене велосипедов и сопутствующих товаров. Бот поддерживает
русский и кыргызский языки, хранит данные в базе SQLite, имеет
публикационный лимит и простую систему локализации.

## Быстрый старт

Следуйте этим шагам, чтобы запустить бота на локальной машине.  Для
производства рекомендуется настроить отдельный бот‑токен и базу данных.

### 1. Установка зависимостей

Убедитесь, что у вас установлен Python 3.11 или новее.  Затем
установите зависимости из `requirements.txt`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
